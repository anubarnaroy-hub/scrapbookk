# Aesthetic Letter Magazine

1. Open this folder in VS Code.
2. Run `npm install` in the terminal.
3. Run `npm run dev`.
4. Open the localhost link shown in Terminal.

## Secret code
In `src/App.jsx`, change `const SECRET_CODE = "birthday22";` to your chosen code.

## Photos
Put your 22 photos in `public/images/` and name them:
`page3-photo1.jpg`, `page3-photo2.jpg`, through `page13-photo1.jpg`, `page13-photo2.jpg`.
If your files are `.jpeg`, rename them to `.jpg` or update the photo path in App.jsx.

## Your letters
Edit the 22 entries inside the `letters` array in `src/App.jsx`.
